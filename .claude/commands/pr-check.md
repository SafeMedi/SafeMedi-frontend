description: PR 생성 전 필수 체크 (git status → yarn lint → yarn test) 실행

CLAUDE.md의 "PR 생성 전 체크" 규칙에 따라 아래 순서로 직접 실행하고 결과를 보고한다.

1. `git status` — uncommitted 변경 사항이 있는지 확인한다. 있다면 어떤 파일인지 나열하고, 커밋할지 여부를 사용자에게 확인한다 (자동으로 커밋하지 않는다).
2. `yarn lint` — Biome 린트 통과 여부 확인. 실패하면 에러를 그대로 보여주고 수정이 필요한 위치를 짚어준다. 자동으로 `yarn lint:fix`를 돌리지 않는다 (사용자가 원할 때만).
3. `yarn test` — 테스트 스위트 통과 여부 확인. 실패 시 실패한 테스트 이름과 원인을 요약한다.

## 금지 사항

- `--no-verify`, `--force` 등 훅·검증 우회 금지.
- 세 단계 중 하나라도 실패하면 "PR 생성 가능"이라고 말하지 않는다.
- 린트·테스트를 고치기 위해 요청 범위 밖의 리팩터링을 하지 않는다.

## 출력

마지막에 3줄 요약으로 보고한다:

- git status: 깨끗함 / N개 파일 uncommitted
- yarn lint: 통과 / 실패 (에러 N개)
- yarn test: 통과 / 실패 (실패 N개)

모두 통과면 "PR 생성 가능"이라고 명시한다.
